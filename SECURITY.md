# Security policy

## Supported versions

Only the latest release receives security fixes. Check the
[releases page](https://github.com/tkronawitter/speaker-buddy/releases) for the current version.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub private vulnerability reporting instead:

1. Open the [Security tab](https://github.com/tkronawitter/speaker-buddy/security) of this repository.
2. Choose "Report a vulnerability".
3. Describe the problem, the affected version and how to reproduce it.

The report stays private between you and the maintainer until a fix is released. This is a
single-maintainer project, so replies may take a few days.

## Scope

The firmware for the timer board and the Windows program that talks to it over USB serial.
